# 伴元 BANYUAN · 一人一伴，共同进化（TR 原型）

温暖陪伴 + 记忆成长的高保真手机 App 原型。纯静态（HTML + CSS + 原生 JS），零依赖、零 CDN，双击 `index.html` 即可离线运行。

## 打开方式

```
双击 index.html（或浏览器打开 file:// 路径）
```

脚本全部是传统 `<script>`（非 ES module），因此 `file://` 下不会被 CORS 拦截。

## 底部三栏 + 设置里的记忆智能体

| 栏目 | 作用 | 关键交互 |
| --- | --- | --- |
| 陪伴 `chat` | 与角色对话 | 打字机、气泡渐入、富文本 + 代码高亮、流式回复、聊天中途「记忆 / 习惯提议卡」 |
| 目标 `goal` | 方向 / 方法 / 成长三段 | 目标卡 + 任务清单 + 计划步骤打勾 + 进度条 |
| 成长 `growth` | 复盘与沉淀 | 待确认复盘 → 确认后进时间线；方法卡（候选 / 已验证） |

记忆不再占底部一栏，改从 **设置 → 记忆智能体** 进入一个独立全屏页。

## 记忆智能体（习惯）

只做两件事，边界清楚：

1. **从对话里自动认出习惯**：主聊天里说到「我每天睡前都要刷会儿手机」，会弹一张习惯提议卡（场景 · 频率 · 可信度 + 原句）；点「存进习惯」才落库。
2. **允许手动添加**：记忆智能体页底部「＋ 手动添加」，填名称 / 触发场景 / 频率即可。

页内还有：已记住的习惯清单（可编辑 / 删除）、一小段专属对话（说一句就整理成候选）、「从最近对话提取」补扫历史消息、折叠的「其他记忆」（方向 / 偏好 / 生活 …）。

- 识别：`STORE.extractHabits()` 按句切分，命中频率词 / 场景词 → 名称 + 场景 + 频率 + 可信度，最多 3 条。
- 默认拒绝：候选只展示，点了才 `STORE.addHabit()`；密码 / 身份证 / 银行卡 / 验证码 / 护照号直接跳过。
- 数据：`habits` 与 `memories` 分开存，都在 `banyuan.v1` 里。

> 陪伴栏的「生活帮手」与「情绪陪伴」已合并为一组「生活与情绪」：生活类请求（清单 / 习惯 / 随便唠唠）也先接住情绪，再给具体办法。收房间和收心情，用的是同一份耐心。

## 话题模板可编辑

陪伴栏右侧「聊天话题模板」面板右上角有一支笔，点一下进入编辑模式：

- **整组调序 / 增删**：组头出现 ↑ ↓ ＋ ✕，可以整组上移下移、新建分组、删除整组。
- **单条增删 / 调序**：每条右侧出现 ↑ ↓ ✕，可以组内调序或删除；组头 ＋ 可在该组新增开场白（标题 / 一句说明 / 会发出去的话 / 图标）。
- **恢复默认**：底部「恢复默认模板」清掉所有自定义，换回内置的 3 组 12 条。
- 改动写进 `localStorage` 的 `banyuan.topics.v1`（与记忆、目标分开存），刷新后仍在；没改过时直接读 `mock.js` 内置模板。
- 退出编辑模式后点条目才发消息；编辑模式下点条目不会误发。

## 伴元功能（S1 闭环）

1. **领养档案**：三步引导（称呼 → 形象 → 摘要确认），写入 `profile`，刷新后保留。
2. **记忆智能体**：`propose()` / `extractHabits()` 从对话里提炼候选记忆与习惯；密码 / 身份证 / 银行卡 / 验证码 / 护照号直接拒收；只有点「保存 / 存进习惯」才落库。
3. **目标 / 计划 / 任务**：目标带指标与截止日；任务状态机 `todo → doing → done → archived`，非法跳转被拒绝。
4. **成长复盘**：复盘先存草稿，点「确认写进成长」才进时间线，同时产生一条 `growth` 记录。
5. **技能方法卡**：从复盘提炼的复用方法，`candidate` / `verified` 两档。

## 角色与形象

- 角色名默认「叮当」，领养时可改，全局通过 `petName()` 读取，不在代码里硬编码。
- 形象配色复用同一份 SVG，靠 `--pet-filter` 做三档（经典蓝 / 月光银 / 暖橘）。
- 宠物状态机：`listening / thinking / responding / celebrating / error / offline`，由 `setPet()` 统一驱动顶栏状态点。

## 模型接入（可选）

设置面板内置 DeepSeek / 通义千问 / 智谱 GLM / Kimi / 豆包 + 自定义，走 OpenAI 兼容 `/chat/completions`（stream）与 `/models`。

- 连接测试：`API.testConnection()`，失败给出 401 / 403 / 404 / 429 / 5xx / CORS 的可读提示。
- 对话：`API.streamChat()` + `ReadableStream`，80ms 节流渲染；未配置或失败自动回落 mock。

## 数据边界

- 所有数据只在这台设备的 `localStorage`（key `banyuan.v1`），不冒充云端。
- 每条记录带 `version` / `updatedAt`，修改走 `patch()` 递增版本，便于日后接后端做 409 冲突。
- 设置里「清空全部数据」会 `STORE.reset()` 并 320ms 后刷新页面。

## 硬约束

- 手机外框只用 SVG 画外壳：`pointer-events:none` + `z-index:0`，屏幕区 `inset:18px` + `z-index:1`，绝不遮挡 UI。
- 不接真实后端；真实模型为可选项，默认走 mock。
- 无 emoji 当图标，全部内联 Lucide 风格 SVG。
